【01】만든 계기 · 세특검토함 · 열매세특

세특검토함 ① 출력한 생기부 더미

"이건 나보다 AI가 잘하겠다"

세특검토함 ② 점검에서 채점으로

점검을 넘어 기록을 개선하고 싶다
지인의 아이디어: 세특을 채점하는 도구 → 채점 기준표가 필요
분야별로 입학사정관 입장에서 본 좋은 기록의 기준

열매세특 — 기준에서 거꾸로

채점 기준을 적용하면 고득점 기록을 만들 수 있겠다
학생 활동 인터뷰를 일괄로 받아 일괄 생성 → 열매카드
열매카드 문항 = 세특검토함 채점 기준 항목

하나로 맞물리다

따로 시작해 서로 영향을 주며 지금에 이르렀다
씨앗카드 → 탐구주제추천 · 열매카드 → 열매세특
채점 기준 → 열매카드 문항 · 세특검토함 → 쓴 기록 점검

출력물 더미 사진이 있으면 나중에 넣을 수 있음(개인정보 가림). 채점 기준표(루브릭)가 열매세특까지 이어지는 출발점. 열매세특은 가장 마지막에 만든 도구 — 검토 기준과 작성 기준이 같다는 점이 핵심. 한 해의 흐름은 5부에서 다시 다룬다.
